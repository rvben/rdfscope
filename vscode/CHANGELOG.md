# Changelog

## 0.1.0 — Preview

- Explore Turtle, RDF/XML, TriG, N-Triples, N-Quads, and JSON-LD files inside VS Code.
- Follow graph connections and inspect exact RDF terms, datatypes, and named graphs.
- Run read-only SPARQL in a full-height pane with a pinned Run button.
- Inspect results in a closable side drawer without leaving the query.
- Use the current editor group by default, with an explicit option to open beside the source.
- Match VS Code themes and adapt to narrow editor panes.
- Reload saved or unsaved source edits and save exploration workspaces and exports.
- Process files locally in a bundled Rust/WebAssembly worker without a server.
